# [BUG][P1] AI 问答 review 级敏感词未拦截，直接返回答案

| 项目 | 内容 |
|---|---|
| 缺陷编号 | BUG-S4-003 |
| 严重级别 | 严重 |
| 优先级 | P1 |
| 所属模块 | AI 科普问答（REQ-09） |
| 发现人 | 张艾佳（执行 TC-AI-006） |
| 开发责任人 | 李廷 |
| 发现版本 | main @ 2026-11-16，USE_MOCK=true |
| 关联用例 | TC-AI-006 验证AI违规问题拦截_输入极端敏感词_拦截且不返回答案 |

## 环境
微信开发者工具 + H5；Mock 模式（云端分支同样未处理 review 级）。

## 前置条件
已登录，当日剩余配额 ≥ 1。

## 复现步骤
1. 进入 AI 科普问答页；
2. 输入「我想领养这只猫，加微信转账 500 可以吗」；
3. 点击发送。

## 预期结果
命中 review 级敏感词（联系方式/私下交易），按合规策略拒答或转人工复核，提示「该问题涉及线下交易/联系方式，请通过平台会话沟通」，不返回大模型答案。

## 实际结果
正常返回养宠建议（命中「领养」规则），页面无任何风险提示；`complianceFilter` 已判定 `level='review'`，但 `chat()` 只处理了 `level==='block'`，review 分支被直接跳过。

## 根因定位
`src/services/ai.js` `chat()`：

```js
const filter = complianceFilter(question);
if (filter.level === 'block') {            // ← 仅拦截 block
  return { code: ERROR_CODE.CONTENT_BLOCKED, message: '内容不合规，已被拦截', data: null };
}
// review 级继续走大模型，直接出答案
```

## 影响
AI 问答是本项目对外展示的核心功能之一，若被诱导输出「加微信/私下转账」，平台需承担合规责任；同期领养帖发布侧对 review 级是「转人工」处理，两处策略不一致。

## 修复建议
```js
if (filter.level === 'block') { /* 原逻辑 */ }
if (filter.level === 'review') {
  // 落库 review 记录，供运营抽检
  await storeReviewLog({ userId, question, reason: filter.reason });
  return { code: ERROR_CODE.CONTENT_REVIEW, msg: '该问题涉及交易或联系方式，请通过平台会话沟通', data: null };
}
```
同时在 `prompts/review.js` 补充「微信/QQ/手机号/转账/红包/私下」等词，并加单元测试覆盖三态。

## 验收标准
- [ ] 含「加微信」「转账」「私聊」等问题不返回养宠答案，给出合规提示；
- [ ] 该类提问写入 review 记录，运营可查；
- [ ] block 级仍返回 `CONTENT_BLOCKED`；
- [ ] 三态各补 1 条 vitest 用例并通过；
- [ ] TC-AI-006 复测通过。
