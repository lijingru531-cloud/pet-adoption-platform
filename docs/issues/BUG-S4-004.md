# [BUG] 科普帖标题仅输入空格即可通过必填校验并发布成功

| 项目 | 内容 |
|---|---|
| 缺陷编号 | BUG-S4-004 |
| 严重级别 | 一般 |
| 优先级 | P2 |
| 所属模块 | 科普发布（REQ-08） |
| 发现人 | 李廷（执行 TC-SCI-003） |
| 开发责任人 | 张艾佳 |
| 发现版本 | main @ 2026-11-16，USE_MOCK=true |
| 关联用例 | TC-SCI-003 验证科普必填项校验_逐项留空_提示精确到字段 |

## 环境
微信开发者工具（Android 真机）+ H5，Mock 模式。

## 前置条件
已登录并绑定手机号，已选择分类、上传封面、填写正文。

## 复现步骤
1. 进入「发布科普」页；
2. 标题输入 3 个空格（`"   "`）；
3. 其余字段正常填写，点击「发布」。

## 预期结果
提示「请填写标题」，不发起创建请求。

## 实际结果
校验通过，请求发出并创建成功；信息流出现一条标题为空白的科普帖，卡片标题区域为空白，标签与摘要仍按正文生成。

## 根因定位
`src/pages/science/post.vue:105`

```js
function validate() {
  if (!form.title) return '请填写标题';   // "   " 为真值，直接通过
  ...
}
```
`form.content` 同理，纯换行/空格也能绕过。

## 修复建议
```js
const title = (form.title || '').trim();
if (!title) return '请填写标题';
if (title.length < 4 || title.length > 40) return '标题需 4~40 个字';
const content = (form.content || '').trim();
if (!content) return '请填写正文';
```
后端 `science.create` 同步做一次 trim 后校验（前端校验可被绕过）；领养帖发布页建议一起排查同类问题。

## 验收标准
- [ ] 标题仅空格时提示「请填写标题」，不发送请求；
- [ ] 正文仅空格/换行时同样被拦截；
- [ ] 正常标题、4~40 字边界值可正常发布；
- [ ] 接口层直接传空白标题返回参数错误；
- [ ] TC-SCI-003 复测通过。
